**Hier hinein gehört, was dort nicht steht:** deine eigene Beobachtung, dein
Aha-Moment, die Erklärung, die bei dir endlich klick gemacht hat.

Eine Notiz, die dasselbe sagt wie `docs/GOLD-SILBER.md`, ist eine Kopie, die veraltet.
Eine Notiz, die sagt „ich habe erst verstanden, was ATR bedeutet, als ich gesehen habe,
dass mein Stop bei 0,8×ATR jedes Mal abgeräumt wurde" — die gibt es nur hier.
