# Alle Trades

<!-- GENERIERT — wird beim naechsten Export ueberschrieben -->

**Noch kein Export gelaufen.**

Diese Seite füllt sich, sobald du im Repo-Ordner ausführst:

```bash
python -m metals vault --journal GoldScalpAssistant.csv
```

Die CSV schreibt der EA selbst. In MetaTrader findest du sie über
**Datei → Datenverzeichnis öffnen** → `MQL5` → `Files`.

Danach steht hier eine Zeile je abgeschlossenem Trade, verlinkt auf die Einzelnotiz, plus
Summe, Trefferquote und eine Aufteilung nach Setup.
